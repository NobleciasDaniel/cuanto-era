Política de privacidad

Cuánto Era recuerda precios sin crear un perfil sobre ti. La extensión procesa la página que eliges y conserva el historial en el almacenamiento local de Chrome; el editor no recibe esos datos.

Lo esencial

La extensión necesita leer la pestaña activa para reconocer un producto. Esa lectura ocurre al abrir Cuánto Era. Nada se guarda hasta que eliges Guardar este precio.

01

Alcance y responsable

Esta política describe el funcionamiento de la extensión de Chrome Cuánto Era, publicada por Daniel Noblecias bajo la cuenta NobleciasDaniel. No cubre las tiendas que visitas ni los servicios de Chrome o GitHub, que operan conforme a sus propias políticas.

02

Información que procesa la extensión

Al abrirla desde una página de producto, Cuánto Era puede reconocer los siguientes datos visibles o publicados por la tienda:

  • título, tienda, dominio y dirección web del producto;
  • identificador y variante, cuando están disponibles;
  • precio actual, precio anterior mostrado y moneda;
  • vendedor, disponibilidad y texto breve de entrega;
  • fecha y hora de la captura.

Cuánto Era no solicita nombre, correo, teléfono, datos de pago, contraseñas, cookies ni credenciales. Sin embargo, una tienda podría incluir información personalizada en su dirección web o texto de entrega; si el usuario decide guardar el estado, ese texto podría conservarse localmente como parte del registro.

03

Cuándo se procesa y cuándo se conserva

Momento Qué ocurre Persistencia
Al abrir Se analiza temporalmente la pestaña activa. No se crea un registro.
Al guardar Se crea o actualiza el historial del producto. Permanece en Chrome.
En segundo plano Solo se actualiza el contador de productos guardados. No se observan páginas.
04

Almacenamiento, retención y eliminación

Los registros se guardan mediante chrome.storage.local en el perfil de Chrome del dispositivo. No se sincronizan entre equipos. Cada producto conserva hasta 500 estados.

Los datos permanecen hasta que el usuario elimina un producto, conserva únicamente su último estado, reemplaza la base mediante una importación o desinstala la extensión. Chrome elimina el almacenamiento local asociado cuando se desinstala Cuánto Era.

05

Transferencias y monetización

La extensión no envía el historial, las páginas examinadas ni los datos de producto al editor o a terceros. No existen servidores de Cuánto Era, cuentas, telemetría, analítica, anuncios ni programas de afiliados. Los datos no se venden, no se utilizan para perfilar usuarios y no son revisados por personas.

Abrir el enlace de un producto es una acción explícita del usuario y conduce al sitio de la tienda. A partir de ese momento se aplican las prácticas de privacidad de esa tienda.

06

Permisos de Chrome

activeTab
Concede acceso temporal a la pestaña elegida cuando el usuario abre la extensión.
scripting
Ejecuta en esa pestaña el extractor incluido dentro de la extensión.
storage
Conserva localmente los productos y precios que el usuario decide guardar.
07

Control del usuario y seguridad

El panel de historial permite consultar, exportar y eliminar los registros sin solicitar intervención del editor. La exportación crea un archivo JSON en el dispositivo; la importación lee únicamente el archivo seleccionado por el usuario.

Cuánto Era no ejecuta código remoto. El historial queda protegido por las medidas del dispositivo y del perfil de Chrome. La extensión no añade una capa propia de cifrado, por lo que cualquier persona con acceso al perfil de Chrome podría acceder a esos registros.

08

Compromiso de uso limitado

La información se utiliza exclusivamente para la función visible de identificar productos, guardar estados de precio y compararlos. El uso de información obtenida mediante las APIs de Chrome cumple con la Política de Datos de Usuario de Chrome Web Store, incluidos sus requisitos de Uso Limitado.

09

Este sitio, cambios y contacto

Esta página informativa se aloja mediante GitHub Pages. GitHub puede registrar datos técnicos de conexión, incluida la dirección IP, por motivos de seguridad conforme a su declaración de privacidad. Esto es independiente de la extensión: Cuánto Era no envía datos del historial a esta página.

Si las prácticas de la extensión cambian, esta política mostrará una nueva fecha de revisión y los cambios materiales se comunicarán antes de aplicarse. Para consultas de privacidad o soporte, abre una consulta en GitHub. No incluyas contraseñas, direcciones ni información de pago.
