Política de privacidad de Cuánto Era

Cuánto Era guarda un historial local de los precios que el usuario decide registrar. No tiene cuentas, publicidad, analítica ni servidores propios.

Datos procesados

Cuando el usuario abre la extensión, Cuánto Era procesa la pestaña activa para reconocer el título y la dirección del producto, precio, moneda, tienda, variante, vendedor, disponibilidad y datos breves de entrega. Esta información se usa exclusivamente para mostrar el precio actual y construir el historial solicitado por el usuario.

Activación y consentimiento

El procesamiento comienza únicamente cuando el usuario pulsa el icono de la extensión. La información solo se conserva después de que el usuario pulsa “Guardar este precio”. La extensión no observa la navegación en segundo plano.

Almacenamiento y transferencia

Los registros se almacenan mediante chrome.storage.local en el dispositivo del usuario. No se transmiten al editor, a servicios de analítica ni a terceros, y no se sincronizan entre dispositivos.

Uso limitado

Los datos se utilizan únicamente para la función visible de guardar y comparar precios. No se venden, no se emplean para publicidad o perfiles, no son revisados por personas y no se utilizan para determinar solvencia o realizar operaciones financieras.

Afiliados y cambios en tiendas

Cuánto Era no utiliza programas de afiliados, no modifica enlaces o cookies, no aplica cupones y no cambia el contenido de los sitios visitados.

Retención, exportación y eliminación

Los datos permanecen en el navegador hasta que el usuario elimina un producto, reemplaza su base mediante la importación o desinstala la extensión. El usuario puede exportar una copia JSON desde el historial.

Seguridad

La extensión no ejecuta código remoto. Solo solicita permisos temporales sobre la pestaña activa y almacenamiento local, necesarios para su propósito declarado.

Contacto

Para consultas de privacidad o soporte, abre una consulta en https://github.com/NobleciasDaniel/cuanto-era/issues/new. No incluyas contraseñas, direcciones ni información de pago.
